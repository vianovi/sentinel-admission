# Task 07 — Staff Operations

## Scope

Audit staff candidate operations, status workbenches, action queues, document/payment review, exam result review, reports navigation, and all staff actions.

## Audit focus

- exact staff authorization;
- data minimization;
- operational presenters reuse central services;
- search/filter correctness;
- pagination/large-data behavior;
- dead or fake buttons;
- action routes/confirmation;
- candidate detail exposure;
- payment transaction presentation;
- queue correctness;
- review auditability;
- frontend/backend contracts;
- code-level accessibility/states.

Visual design remains human-reviewed.

## General constraints

- Verify actual source before relying on task hints.
- No schema, production dependency, business-policy, or production-operation change without authority.
- No visual approval claim.
- Store detailed evidence and update durable state.
- Apply all relevant release gates.
